ClassPulseAI

Version 2 — Rule-Based Draft Behavior-Support Plan Tool

Purpose: ClassPulseAI helps educators organize de-identified observations and create a structured draft behavior-support plan for human review.
How this version works: This browser-based prototype uses predefined rules to organize the information you enter. It does not connect to a live AI or LLM service. The recommendations are suggestions for educator review, not automated decisions.
Privacy reminder: Enter only de-identified information needed for this educational task. Do not enter student names, diagnoses, medical information, or unnecessary information about other students.

Step 1: Enter Student Observation Information

Required fields are marked with an asterisk (*). Use specific, observable descriptions.

Avoid labels such as “unmotivated” or “disruptive.” Describe the observable action instead.

If you report a number, identify which specific behavior the number measures. A range such as “2–4 times” can be used if you identify what is being counted.

Step 2: Review Draft Support Plan

Draft created. Review all recommendations before using the plan.
